# PesoPulse 💸

A modern, mobile-first web application designed to help users monitor their personal finances, track savings goals, and automatically calculate Philippine government contributions. Built with a focus on intuitive Human-Computer Interaction (HCI), PesoPulse offers a clean, iOS-inspired interface with forgiving error recovery.

## ✨ Features

* **Smart Salary Input:** Enter your gross salary and let PesoPulse automatically calculate your mandatory Philippine government deductions (SSS, PhilHealth, Pag-IBIG, and an estimated Income Tax).
* **Dynamic Pending Bills:** Add custom bills, track their due dates, and settle them directly from the dashboard.
* **Visual Spending Dashboard:** A beautifully integrated `Chart.js` doughnut chart that updates in real-time as you spend.
* **Savings Goal Tracker:** Set a financial target and watch your progress bar fill up as your available balance grows.
* **Smart Ledger & History:** View all your past transactions, neatly grouped by Month and Year, with a built-in category filter.
* **Error Prevention (Undo System):** Accidentally paid the wrong bill? PesoPulse features a robust state-saving Undo button that completely reverses your last action.
* **Interactive Empty States:** Friendly, visual feedback when you've cleared all your bills or taxes to keep the UI clean.

## 🛠️ Tech Stack

* **Frontend Structure:** HTML5
* **Styling:** CSS3 & Bootstrap 5.3 (Custom CSS variables, iOS-style frosted glass notifications, smooth page transitions)
* **Interactivity & Logic:** Vanilla JavaScript (ES6+)
* **Data Visualization:** Chart.js

## 🚀 Getting Started

PesoPulse is entirely client-side and requires no complex backend, database, or build tools to run locally.

1.  **Clone or Download** this repository to your local machine.
2.  Open the folder containing the project.
3.  Double-click `index.html` to open it in your preferred web browser.
4.  *Tip: Use mobile viewing mode in your browser's Developer Tools for the best experience.*

## 📱 User Experience (UX) Highlights

Designed with core usability heuristics in mind:
* **Visibility of System Status:** Smooth, floating notifications alert you whenever a transaction is saved, a goal is updated, or a bill is settled.
* **User Control and Freedom:** The quick "Undo" feature allows users to recover from accidental clicks immediately without navigating away.
* **Aesthetic and Minimalist Design:** Uses clean whitespace, soft shadows, large tap targets, and color-coded tags to reduce cognitive load. 
* **Fitts's Law Applied:** Large, accessible modal buttons (like the enlarged "Pay Now" and "Cancel" buttons) make the app highly thumb-friendly.
